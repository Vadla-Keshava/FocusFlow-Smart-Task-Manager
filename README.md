# FocusFlow — Frontend Task Manager

A responsive task management app built with **HTML5, CSS3 and vanilla JavaScript**.

## Features
- Add tasks with high, medium or low priority
- Mark tasks as completed or in progress
- Filter all, active and completed tasks
- Delete individual tasks or clear all completed tasks
- Dashboard counts update automatically
- Tasks persist in the browser with `localStorage`
- Responsive layout for desktop and mobile

## Run locally
No installation or build tools are required.

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the **Live Server** extension.

## GitHub upload commands
Create an empty repository on GitHub, then run these commands in the project folder:

```bash
git init
git add .
git commit -m "Create FocusFlow task manager frontend"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/focusflow-frontend.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.

## Concepts practiced
DOM manipulation, events, arrays, objects, filtering, `localStorage`, form validation and responsive CSS.
